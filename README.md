## 简介

**基金投资指南**是一个 AI Skill（技能），专为基金分析和投资指导设计。它采用德鲁克管理思想的核心原则——**成果导向**、**调查研究**、**抓主要矛盾**——帮助用户系统性地评估基金产品。

### 核心特点

- **场景化分析**：根据用户问题自动识别分析场景（单只基金、多基金对比、次新基金、行业主题基金）
- **穿透式评估**：不看宣传材料，看持仓、费率、经理操作逻辑
- **多维度体检**：六维度评分体系，覆盖策略、费率、风险、持仓、经理、流动性
- **中文优化**：专为中国基金市场设计，支持 A 股、港股通、QDII 等

## 适用场景

| 场景 | 示例问题 |

## 使用方法

### 作为 AI Skill 使用

1. 将本技能导入支持 Skill 标准的 AI 助手
2. 向 AI 提出基金相关问题
3. AI 将自动识别场景并调用相应的分析框架

### 示例对话

**示例 1：单只基金分析**

## 分析框架概览

### 六维度评分体系

| 维度 | 权重 | 核心问题 |
|------|------|---------|
| 策略定位 | 15% | 这基金做什么？逻辑是什么？ |
| 费率结构 | 20% | 收了多少钱？隐性成本算了吗？ |
| 风险收益 | 25% | 脾气怎么样？夏普/卡玛比率如何？ |
| 持仓质量 | 15% | 实际买了什么？集中度和风格？ |
| 基金经理 | 15% | 掌舵人靠谱吗？能力圈在哪？ |
| 流动性 | 10% | 规模合适吗？申赎方便吗？ |

### 核心原则

1. **不预测未来收益**：分析基金质量，不预测价格走势
2. **决策交还用户**：提供分析角度和风险提示，不做绝对建议
3. **数据不足说明局限**：没有数据就不评，不用猜测填充
