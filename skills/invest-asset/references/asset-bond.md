# 债券资产细则（bond）

> 债券是借贷凭证，核心是偿付能力，不是价格博弈。买债券先问：能还本付息吗？
> 本文件由 invest-asset 在识别到「债券/利率债/信用债」时加载，是债券资产的专属三关细则。

---

## 先分类

| 类别 | 特征 | 评估重点 |
|------|------|---------|
| 利率债（国债/政金/地方） | 信用风险极低 | 利率风险（久期）、再投资 |
| 信用债（企业/城投/金融） | 有违约风险 | 偿债能力、信用利差 |
| 可转债 | 股债双性 | 见 `asset-convertible.md`（本技能内，不在此重复） |

---

## 三关审查

### 第一关：懂偿付吗（底层确定性）

- 利率债：谁发？政府/政策性信用，偿付几乎无悬念。看久期与利率方向。
- 信用债：发债人赚钱吗？现金流的债？资产能覆盖吗？
  - 指标：资产负债率、利息保障倍数、经营现金流/利息、评级与展望
  - 城投：当地财政、债务率、政企关系；企业：行业景气、盈利稳定性
- **未通过**：说不清偿付来源 → 不碰。

### 第二关：收益好吗（与同等级比）

- 核心是**信用利差** = 信用债收益率 − 同期限国债收益率
- 利差在历史高位 → 补偿足够，值得；利差低位 → 风险补偿不足
- 观察：超额收益来自信用下沉吗？久期拉长吗？
- **未通过**：利差薄风险厚 → 不值得。

### 第三关：贵不贵（收益率/利差位置）

| 指标 | 当前 | 历史分位 | 判断 |
|------|------|---------|------|
| 到期收益率 | ___ | ___% | 高位/中位/低位 |
| 信用利差 | ___bp | ___% | 补偿足/不足 |
| 期限利差 | ___bp | ___% | 陡/平 |
| 久期 | ___ | __ | 利率敏感度 |

- **未通过**：当前收益率覆盖不了违约风险 → 等更优价格。

```markdown
| 关卡 | 结果 | 关键发现 |
|------|------|---------|
| 懂偿付 | 通过/未通过 | __ |
| 收益好 | 通过/未通过 | __ |
| 贵不贵 | 通过/未通过 | __ |

## 关键数据
- 到期收益率/历史分位 / 信用利差/分位 / 期限利差 / 发行人评级
- 风险点：违约、利率上行、流动性、再融资

## 结论
三关全过 + 收益率/利差在历史中高分位 → 可考虑；否则观望。
免责声明：基于公开信息的分析框架，不构成投资建议。
```

## 核心原则

1. **偿付优先**：利率债看利率风险，信用债先看违约概率。
2. **利差是锚**：看不清信用债，就比信用利差的历史分位。
3. **久期匹配**：久期与你的资金期限匹配，别拿短钱配长债。
4. **不赌债牛熊**：看当前收益率是否值得，不预测利率。
