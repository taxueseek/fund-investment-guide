# 季报/年报深度分析框架

> 个人投资者的财报深读指南。不是教你看懂三张表，是教你怎么从财报里挖出别人看不到的东西。

---

## 一、Beat/Miss 分析：量化 vs 预期的偏差

beat/miss 不是看"赚了多少钱"，是看"赚的比预期多/少多少，为什么"。

| 指标 | 计算方法 | 解读 |
|------|----------|------|
| 收入偏差率 | (实际-预期)/预期 ×100% | >5% 为显著 beat，<-5% 为显著 miss |
| 净利润偏差率 | (实际-预期)/预期 ×100% | 注意扣非后口径 |
| EPS 偏差率 | (实际-预期)/预期 ×100% | 最直观的 beat/miss 指标 |
| 毛利率偏差 | 实际毛利率-预期毛利率 | 正偏差=成本控制好或提价成功 |

**偏差归因**：
- **可持续 beat**：量价齐升、份额扩张、新产品放量 → 好信号
- **一次性 beat**：资产处置收益、政府补贴 → 要打折看
- **结构性 miss**：需求萎缩、竞争加剧 → 恶化信号
- **暂时性 miss**：季节因素、交期延迟 → 可能是机会

注意：A股分析师覆盖少，一致预期可能不准。优先看3家以上覆盖的标的。

## 二、收入拆解：量价分离、地域拆分、业务线拆分

### 2.1 量价分离（收入 = 量 × 价）

| 情景 | 量 | 价 | 含义 |
|------|----|----|------|
| 量升价稳 | ↑ | → | 需求增长，但缺乏定价权 |
| 量稳价升 | → | ↑ | 提价能力强，可能是好品牌 |
| 量价齐升 | ↑ | ↑ | 最好——需求强+定价权 |
| 量升价跌 | ↑ | ↓ | 可能在打价格战 |
| 量价齐跌 | ↓ | ↓ | 最差——业务在恶化 |

### 2.2 地域拆分
- 各区域收入增速差异：国内 vs 海外
- 海外收入占比变化：真出海还是汇率波动？
- 注意汇率影响：可能贡献/拖累 2-5 个百分点

### 2.3 业务线拆分
- 各业务线增速：哪些加速，哪些减速
- 毛利率差异：高毛利业务占比变化决定整体盈利能力
- 新业务爬坡：关注收入增速和亏损收窄趋势

## 三、盈利质量检查：六个核心指标

### 3.1 经营现金流 / 净利润比率
| 比率 | 解读 |
|------|------|
| >1 | 利润质量高，赚的是真金白银 |
| 0.7-1 | 可接受，关注波动原因 |
| 0.5-0.7 | 警惕，利润中可能有较多应收 |
| <0.5 | 严重警示，利润可能是纸面数字 |
| 为负 | 最危险信号之一——利润为正但经营现金流为负 |

### 3.2 应收账款周转天数
**公式**：应收账款 / 日均营业收入。对比近4-8个季度趋势。
- 天数上升 = 回款变慢 = 议价能力下降或放宽信用政策
- 异常信号：突然大幅上升，可能在向渠道压货

### 3.3 存货周转天数
**公式**：存货 / 日均营业成本
- 天数上升 = 存货积压，可能需要减值
- 异常信号：存货增速远超收入增速——产品可能卖不动了
- 行业差异：白酒存货天数高不代表差（基酒要放几年）

### 3.4 资本开支 / 折旧比率
| 比率 | 解读 |
|------|------|
| 1-2 | 正常维护性投资 |
| 2-3 | 扩张性投资，看好未来 |
| >3 | 激进扩张，警惕产能过剩 |
| <1 | 可能在收缩，未来增长存疑 |

### 3.5 研发费用资本化比例
**公式**：资本化研发支出 / 研发总投入
- 合理范围：<30%；警示信号：>50% 或突然大幅提高
- 对比同行：如果同行都不资本化但你在资本化，要问为什么

### 3.6 商誉 / 净资产比率
| 比率 | 风险等级 |
|------|----------|
| <10% | 低风险 |
| 10-30% | 中等，需关注减值迹象 |
| 30-50% | 高风险，减值可能吞噬净资产 |
| >50% | 极高——减值一次可能净资产为负 |

## 四、A股特有红旗信号

**商誉减值风险**：看并购标的业绩承诺完成情况。承诺期刚过就变脸 = 减值信号。行业下行周期中高商誉公司最先暴雷。

**大股东质押比例**：
| 质押比例 | 风险等级 |
|----------|----------|
| <30% | 正常 |
| 30-50% | 需关注 |
| 50-70% | 高风险，平仓线逼近时股价容易被砸 |
| >70% | 极高风险——大股东可能缺钱，利益输送风险大 |

**关联交易变化**：金额大幅增长可能有利益输送；关联方应收账款增长快可能虚增收入。

**审计师变更**：更换为更小的审计机构 → 严重警示。连续更换审计师 → 公司治理可能存在重大问题。

**非经常性损益占比**：>30% 利润含金量低不可持续；>50% 主业可能不赚钱靠一次性收益撑门面。

---

## 五、港股特有关注项

**审计师意见类型**：无保留意见（正常）→ 带强调事项段（中等）→ 保留/否定/无法表示意见（严重）。

**关联交易披露**：港股按《上市规则》第14A章要求更严格，需看独立财务顾问意见，持续关联交易需年度审核。

**会计准则差异 (HKFRS vs CAS)**：A+H 股公司两份报表可能有差异。常见来源：收入确认时点、金融工具分类、租赁准则。关注港股"其他全面收入"科目。

## 六、管理层语调分析

不是听管理层说什么，是听他们**怎么**说，以及**不说什么**。

| 维度 | 正面信号 | 负面信号 |
|------|----------|----------|
| 措辞变化 | "超出预期"、"加速增长" | "充满挑战"、"短期承压" |
| 回避问题 | 详细回答 | 模糊带过、转移话题 |
| 前瞻指引 | 给出明确指引 | 反复强调"不确定性" |
| 数据引用 | 引用具体数据 | 大量定性描述 |

**跨季度对比重点**：CFO 回答语气是主动还是被动？管理层对坏消息归因于外部还是内部？"战略重点"说了几遍但没进展？

---

## 七、隐藏信号：魔鬼在细节里

**资本开支趋势**：CapEx 增速远超收入增速 = 产能可能过剩。在建工程延迟转固 = 可能在推迟折旧。

**营运资金变化**：(应收天数+存货天数-应付天数) 趋势。应收项目增加可能是放宽信用政策；应付项目增加可能是挤压供应商。

**表外项目**：担保余额/净资产比率、未决诉讼金额、合并范围变化（新增=并购，减少=甩包袱）。
