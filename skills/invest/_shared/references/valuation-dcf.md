# DCF 估值方法论参考手册

> 本文档为个人投资者提供完整的 DCF 估值方法论，基于机构级框架简化适配，
> 数据源以东方财富 API 为准。适用于 A 股和港股标的。

---

## 1. DCF 的本质

**一家公司值多少钱 = 它未来能赚到的所有自由现金流，折算到今天值多少。**

```
企业价值 (EV) = Σ [FCFt / (1+WACC)^t] + TV / (1+WACC)^n
```

- `FCFt`：第 t 年自由现金流 | `WACC`：加权平均资本成本 | `TV`：终值 | `n`：预测期年数（5-10 年）

---

## 2. 十步完成 DCF 估值

| 步骤 | 内容 | 关键决策 | 数据来源 |
|------|------|----------|----------|
| 1 | **理解业务** | 收入驱动因素、竞争格局 | 东方财富个股页面、年报 |
| 2 | **收集历史数据** | 至少 5 年三表数据 | 东方财富财务数据 API |
| 3 | **构建收入预测** | TAM×份额 或 量×价 | 行业研报、东方财富行业数据 |
| 4 | **预测利润表** | 毛利率/营业利润率趋势 | 历史数据 + 同业对比 |
| 5 | **预测自由现金流** | FCFF = NOPAT + D&A − CapEx − ΔWC | 步骤 4 推导 |
| 6 | **计算 WACC** | 资本结构、成本、税率 | 东方财富市场数据 |
| 7 | **计算终值** | 永续增长法或退出倍数法 | 同步骤 6 |
| 8 | **折现并求和** | 年中惯例调整 | 步骤 5-7 汇总 |
| 9 | **EV→股权价值桥接** | 加回现金、减负债等 | 东方财富资产负债表 |
| 10 | **敏感性分析与情景** | 5×5 网格 + 三情景 | 所有步骤汇总 |

## 3. WACC / CAPM 计算（中国市场参数）

### 3.1 WACC 公式

```
WACC = E/(E+D) × Re + D/(E+D) × Rd × (1-T)
```

| 符号 | 含义 | 获取方式 |
|------|------|----------|
| `E` | 股权市值 | 东方财富实时行情 API |
| `D` | 有息负债 | 短期借款+长期借款+应付债券（东方财富资产负债表） |
| `Re` | 股权成本 | CAPM 计算（见下） |
| `Rd` | 债务成本 | 利息费用 / 有息负债 |
| `T` | 有效税率 | 通常 15%-25%（高新技术企业 15%） |

### 3.2 CAPM 股权成本

```
Re = Rf + β × ERP + α（特定风险溢价）
```

| 参数 | A 股 | 港股 | 说明 |
|------|------|------|------|
| **Rf（无风险利率）** | 中国 10Y 国债收益率（约 2.3%-2.8%） | 同左 | **用中国国债，不用美国国债** |
| **β** | 个股 vs 沪深 300 | 个股 vs 恒生指数 | 东方财富可查或自行回归（2-5 年周数据） |
| **ERP（股权风险溢价）** | **5%-7%** | **6%-8%** | A 股常用 5.5%-6.5%，港股因外资参与度高略高 |
| **α（特定风险溢价）** | 0%-3% | 0%-3% | 小市值+1-2%，高杠杆+1%，治理风险+1% |

### 3.3 WACC 典型区间

| 公司类型 | A 股 WACC | 港股 WACC |
|----------|----------|----------|
| 大型央企/国企 | 7%-9%（典型 8%） | 8%-10%（典型 9%） |
| 优质民企龙头 | 9%-12%（典型 10%） | 10%-13%（典型 11%） |
| 中小盘成长股 | 11%-14%（典型 12%） | 10%-14%（典型 11%） |

> WACC 每变动 1%，估值可能变动 15-25%。敏感性分析中对 WACC 做 ±1% 网格。

## 4. 终值计算：永续增长法

### 4.1 公式

```
TV = FCFn+1 / (WACC - g)
```

### 4.2 关键约束

| 约束 | 说明 |
|------|------|
| **g < WACC** | 否则数学上无意义 |
| **g ≤ GDP 长期增速** | 中国名义 GDP 约 4%-5%，公司不可能永远跑赢经济体 |
| **g 通常取 2%-4%** | 成熟公司 2%-3%，赛道龙头 3%-4% |
| **终值占 EV 比例** | **50%-70%**；>80% 说明近期 FCF 预测不够自信 |

### 4.3 替代方法

退出倍数法：`TV = EBITDA_n × 行业当前 EV/EBITDA × 0.7-0.9`。两种方法取平均更稳健。

## 5. 年中惯例（Mid-Year Convention）

现实中现金流均匀分布在全年，而非年末一次性产生。年中惯例假设现金流在 7 月 1 日产生。

| 年份 | 年末惯例 | 年中惯例 | 差异 |
|------|---------|---------|------|
| 第 1 年 | 1/(1+WACC)^1 | 1/(1+WACC)^0.5 | 现值更高 |
| 第 2 年 | 1/(1+WACC)^2 | 1/(1+WACC)^1.5 | 现值更高 |
| 第 n 年 | 1/(1+WACC)^n | 1/(1+WACC)^(n-0.5) | 现值更高 |

```
PV of FCF_t = FCF_t / (1+WACC)^(t-0.5)    ← 年中惯例
PV of TV    = TV   / (1+WACC)^n            ← 终值仍在年末
```

年中惯例通常使估值提高 2%-5%。

## 6. 企业价值 → 股权价值桥接

DCF 直接算出的是**企业价值（EV）**，需桥接转换为**股权价值**：

```
股权价值 = EV + 现金 − 有息负债 − 少数股东权益 − 优先股 ± 其他调整
```

| 项目 | 金额（亿元） | 数据来源 |
|------|------------|----------|
| **企业价值（EV）** | XXX | DCF 计算 |
| ＋ 现金及等价物 | XXX | 货币资金+交易性金融资产 |
| − 短期借款 | XXX | 东方财富资产负债表 |
| − 长期借款 | XXX | 东方财富资产负债表 |
| − 应付债券 | XXX | 东方财富资产负债表 |
| − 租赁负债（IFRS 16） | XXX | 新准则下需单列 |
| − 少数股东权益 | XXX | **存在时必须扣除** |
| − 优先股 | XXX | 多数 A 股为 0 |
| ＋ 联营/合营投资溢价 | XXX | 公司公告 |
| **= 股权价值** | **XXX** | |
| ÷ 完全稀释股本（亿股） | XXX | 含期权/SAR/可转债 |
| **= 每股内在价值** | **XXX** | |

```
安全边际 = (每股内在价值 − 当前股价) / 每股内在价值
>30%：具有投资价值 | 15-30%：值得关注 | <15%：等待更好时机 | <0%：高于内在价值
```

## 7. 三情景分析与敏感性表格

### 7.1 三情景定义

## 8. A 股 / 港股特殊调整

### 8.1 AH 溢价

| 因素 | 影响 | 调整建议 |
|------|------|----------|
| 流动性差异 | A 股散户多、换手率高 | H 股估值加 10-15% 流动性折价 |
| 投资者结构 | A 股散户主导，H 股机构主导 | 以 H 股估值为锚 |
| 资本管制 | 陆股通/港股通有额度限制 | 溢价持续存在，AH 溢价 15-30% 为合理区间 |
| 税收差异 | 港股通股息税 20% | 高股息标的需在 H 股估值中扣税 |

### 8.2 流动性折价

| 日均成交额 | 建议折价 |
|-----------|---------|
| > 5 亿元 | 0% |
| 1-5 亿元 | 5-10% |
| < 1 亿元 | 10-20% |
| 新三板/北交所部分标的 | 20-30% |

### 8.3 其他 A/H 股调整

- **限售股**：大股东持股实际受限（减持新规），估值时用实际流通市值
- **政策风险折价**：反垄断（互联网平台 5-15%）、行业政策突变（教培/地产 10-30%）、数据安全（出海科技 5-10%）
- **壳价值**：市值 <30 亿小盘 A 股可能存在壳价值（注册制后已大幅下降），DCF 需与可比公司法交叉验证

## 9. 常见陷阱与规避

| # | 陷阱 | 规避 |
|---|------|------|
| 1 | 用美国无风险利率 | **用中国 10Y 国债收益率**（2.3-2.8%） |
| 2 | 永续增长率设太高 | g ≤ 4%，且 < WACC 至少 4 个百分点 |
| 3 | 忽略年中惯例 | 统一用 t-0.5 折现 |
| 4 | 预测期太短（终值>80%） | 至少 5 年，高增长公司 7-10 年 |
| 5 | 收入线性外推 | 分阶段：高增长→减速→稳态 |
| 6 | 忽略营运资本变动 | 每年计算 ΔWC = Δ应收 + Δ存货 − Δ应付 |
| 7 | 忘记扣少数股东权益 | 桥接表中明确列出 |
| 8 | 单一情景 DCF | 做三情景 + 敏感性表格 |
| 9 | 不检查终值占比 | 保持在 50-70% |
| 10 | 忽略股权稀释 | 用完全稀释股份数（含期权/SAR/可转债） |

## 10. 完整输出示例结构

以招商银行（600036.SH / 3968.HK）为例。

> **银行股特殊说明**：银行没有传统意义的 FCF（资金本身就是"存货"），因此银行估值用 **DDM（股利折现模型）** 而非 FCFF。核心逻辑一致——把未来能分给股东的钱折现回来。

### 10.1 关键假设

| 假设项 | 悲观 | 基准 | 乐观 | 驱动因素 |
|--------|------|------|------|---------|
| 净息差（NIM） | 2.0% | 2.3% | 2.5% | 利率环境、资产结构 |
| 贷款增速 5Y CAGR | 6% | 9% | 12% | 经济复苏、零售需求 |
| 成本收入比 | 33% | 30% | 28% | 数字化降本 |
| 不良率 | 1.0% | 0.95% | 0.90% | 资产质量趋势 |
| ROE | 14% | 16% | 18% | 杠杆×息差×效率 |
| 派息率 | 33% | 35% | 37% | 监管要求、资本充足 |
| 折现率（Re） | 11% | 10% | 9% | CAPM 计算 |
| 永续增长率 | 2.0% | 3.0% | 3.5% | ≤ GDP 增速 |

### 10.2 每股股利预测（基准）

| 年份 | 第 1 年 | 第 2 年 | 第 3 年 | 第 4 年 | 第 5 年 |
|------|--------|--------|--------|--------|--------|
| 归母净利润（亿元） | 1,550 | 1,680 | 1,820 | 1,970 | 2,130 |
| 每股收益 EPS（元） | 6.15 | 6.67 | 7.22 | 7.82 | 8.45 |
| 每股股利 DPS（元） | 2.15 | 2.33 | 2.53 | 2.74 | 2.96 |
| 折现因子（年中） | 0.952 | 0.907 | 0.864 | 0.823 | 0.784 |
| PV of DPS | 2.05 | 2.12 | 2.19 | 2.25 | 2.32 |

### 10.3 估值汇总与三情景

| 项目 | 金额 |
|------|------|
| 显式期 PV（5 年股利折现） | 10.93 元 |
| 终值 PV（永续增长法） | 30.5 元 |
| **= 每股内在价值** | **41.4 元** |
| 当前股价 / **安全边际** | ~38 元 / **~8%** |

> **银行股 DDM 要点**：终值占比通常 60-75%（比一般企业更高），这是正常的——银行利润稳定，远期现金流占比天然更大。但如果终值 >80%，说明近期预测不够自信。

| 情景 | 概率 | 每股价值 | 加权贡献 |
|------|------|---------|---------|
| 悲观（NIM 压缩、不良上升） | 25% | 33 元 | 8.3 元 |
| 基准（温和增长、资产质量稳定） | 55% | 41 元 | 22.6 元 |
| 乐观（零售复苏、财富管理高增） | 20% | 52 元 | 10.4 元 |
| **加权估值** | | | **41.3 元** |

> **招行特殊优势**：零售银行龙头，非息收入占比高（财富管理、信用卡、托管），比纯对公银行更抗息差压缩。这是 DDM 中"乐观情景"的核心支撑。

## 11. 数据来源与附录

所有数据均可通过东方财富 API 获取（股价行情、三表数据、股本结构、Beta、AH 溢价、限售解禁、研报等），
无风险利率取中债 10Y 国债收益率。

**FCFF = EBIT × (1-T) + D&A − CapEx − ΔWC**，其中 ΔWC = Δ应收 + Δ存货 + Δ预付 − Δ应付 − Δ预收 − Δ合同负债。
资本结构稳定用 FCFF+WACC（最常用）；变化大用 FCFE+Re；金融行业用 DDM。

**完成后检查清单：**
- [ ] 用中国国债收益率（非美国）
- [ ] 永续 g < WACC 且 ≤ 4%
- [ ] 终值占 EV 50-70%
- [ ] 使用年中惯例（t-0.5）
- [ ] 桥接表扣少数股东权益
- [ ] 完全稀释股本
- [ ] 三情景 + 5×5 敏感性
- [ ] CapEx/D&A 比率合理
- [ ] A/H 股分别考虑流动性与税收差异

> **DCF 不是精确科学，而是结构化思考框架。**
> 它的价值不在于算出一个精确数字，而在于迫使你思考：
> 这家公司靠什么赚钱？能赚多久？增速能维持吗？
