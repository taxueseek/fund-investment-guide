# 工作流 D：一致预期整合

> 回答「市场怎么看这个标的」——不是搜几个目标价罗列，而是理解市场共识的结构：共识在哪、分歧在哪、共识是否已经反映在价格里。

---

## 适用场景

- 「分析师怎么看 XX」「市场对 XX 一致预期」
- 「XX 的目标价分布」「机构给 XX 的评级」
- 「买方和卖方对 XX 的共识是什么」
- 「市场对 XX 的预期差在哪」「市场在想什么」
- 「wind 一致预期 XX」「XX 的一致预期 EPS」

---

## 核心认知

一致预期的价值不在「平均目标价是多少」，而在：

1. **共识方向**：机构一边倒看多/看空 → 你要问：已经 price in 了吗？
2. **分歧点**：不同机构看法差异的核心来源是什么？（增长预期？竞争格局？政策？）
3. **预期差**：你的判断和市场共识有什么差异？差异就是你利润的来源（也是你错误的来源）
4. **变化趋势**：一致预期正在上调还是下调？这个方向本身很重要

## 执行步骤

### Step 0：获取一致预期数据

用 invest-cli（`intent` `wind` `info`） / web_search 获取：

- 一致预期 EPS（未来 1-2 年）
- 一致预期营收（未来 1-2 年）
- 目标价分布（最高/最低/中位数/平均）
- 评级分布（买入/增持/中性/减持/卖出 各占 %）
- 近期评级变化（过去 1-3 个月哪家上调/下调）

**如果找不到足够数据**（如小盘股、缺乏卖方覆盖）→ 说明数据不足，降低分析深度，不只靠猜。

### Step 1：共识画像

#### 1.1 方向判断

| 维度 | 判断 |
|------|------|
| 一致预期方向 | [ ] 看多（目标价>现价 15%+）/ [ ] 中性（±15%）/ [ ] 看空 |
| 评级分布 | 买入__% / 增持__% / 中性__% / 减持__% |
| 近期趋势 | [ ] 上调中 / [ ] 稳定 / [ ] 下调中 |
| 覆盖数量 | __ 家机构（<5 家注意样本偏差） |

#### 1.2 目标价分布

```
最高目标价：__ 元（__% 空间）— {给出机构}
最低目标价：__ 元（__% 空间）— {给出机构}
中位数：__ 元（__% 空间）
平均数：__ 元（__% 空间）
现价：__ 元

离散系数：（最高-最低）/ 中位数 = __%（>50% 说明分歧大）
```

### Step 2：分歧分析

目标价差异背后是逻辑差异。要回答：**为什么机构 A 给 100 元而机构 B 给 80 元？**

常见分歧来源：

| 分歧来源 | 说明 | 示例 |
|---------|------|------|
| 增长预期差 | 对营收/利润增速假设不同 | A 假设 30%，B 假设 15% |
| 估值倍数差 | 给的 PE/PB 不同 | A 给 30x，B 给 20x |
| 竞争格局判断 | 对护城河的看法不同 | A 认为优势扩大，B 认为正在收窄 |
| 政策/外部因素 | 同一政策解读不同 | A 认为利好龙头，B 认为利空全行业 |
| 时间维度 | 短期 vs 长期逻辑权重不同 | A 看 3 年，B 下季度不达预期就下调 |

至少识别 2 个核心分歧点，每个分歧点标明：正方 + 反方。

### Step 3：共识合理性检验（关键步骤）

市场共识不等于正确。要检验：

**3.1 数字一致性检验**：
- 目标价 = EPS × PE。EPS 假设和 PE 假设是否匹配？
- 高 EPS 假设 + 低 PE 假设 = 矛盾（要么增长被高估，要么风险被低估）

**3.2 历史一致性检验**：
- 过去 12 个月一致预期的 EPS 准确度如何？（经常高估/低估说明体系偏差）
- 过去的目标价兑现率？

**3.3 逻辑一致性检验**：
- 「碳中和利好所有新能源」→ 太笼统，每个环节逻辑不同
- 「AI 都受益」→ 要具体分析算力/模型/应用各自的逻辑

### Step 4：你的立场（相对于共识）

```
市场共识：[一句话]
我们的差异：[一句话]
差异来源：[增速假设/估值假设/竞争判断/其他]
差异可持续性：[大/中/小]

结论：
[ ] 我和共识一致 → 需要找 other 的 α
[ ] 我比共识乐观 __% → 如果我是对的，空间在 __
[ ] 我比共识悲观 __% → 共识可能过度乐观，回调风险 __
```

### Step 5：共识陷阱识别

| 陷阱 | 特征 | 概率 |
|------|------|------|
| 羊群效应 | 近 3 个月密集上调/下调，无新信息 | 高/中/低 |
| 锚定效应 | 目标价密集在某个整数附近 | 高/中/低 |
| 信息滞后 | 财报出了一次，目标价没动 | 高/中/低 |
| 乐观偏差 | 一致预期持续高于实际兑现 | 高/中/低 |
| 样本偏差 | <5 家覆盖，中位数不可靠 | 高/中/低 |
| 利益冲突 | 投行目标价和承销关系相关 | 高/中/低 |

## 质量门禁

- [ ] 目标价来源是否标注了机构（不说「机构目标价__」，说「__ 券商目标价__」）？
- [ ] 是否分析了分歧（不说「市场目标价围绕 __」，要回答为什么差异）？
- [ ] 是否有共识合理性检验？
- [ ] 是否有「你的立场 vs 共识」？一致性分析不是为了统计，是为了找预期差
- [ ] 是否有共识陷阱识别？
- [ ] 是否区分了「事实」（机构给的目标价）和「解读」（是否合理）？
- [ ] 覆盖机构 <5 家时是否标注了样本偏差风险？
- [ ] 来源是否标注？
