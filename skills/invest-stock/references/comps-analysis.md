# 可比公司分析 (Comparable Company Analysis, Comps)

> 改编自 Anthropic 金融开源项目，适配中国个人投资者。Comps 是最常用也最容易用错的估值方法。

---

## 一、核心原则：5-10 法则

Comps 表格列数不超过 **10 列**：
- **5 个经营指标**：反映业务质量
- **5 个估值指标**：反映市场定价

超过 10 列，人类大脑无法有效对比，噪音掩盖信号。

### 经营指标选择（按行业选 5 个）

| 行业 | 推荐经营指标 |
|------|------------|
| 消费 | 收入增速、毛利率、同店增长(SSG)、CAC、复购率 |
| 科技 | ARR、NDR、收入增速、Rule of 40、毛利率 |
| 金融 | 净息差(NIM)、不良率(NPL)、拨备覆盖率、ROE、资本充足率 |
| 工业 | 收入增速、毛利率、订单积压(Book-to-Bill)、ROIC、产能利用率 |
| 医药 | 研发管线数量、研发/收入比、收入增速、毛利率、自由现金流 |

### 估值指标通用模板（5 个）

1. **P/E** — 最通用，盈利为负时失效
2. **EV/EBITDA** — 资本结构差异大时更公平
3. **P/S** — 亏损公司可用
4. **P/B** — 重资产行业适用
5. **PEG** — 高增长公司适用（PE / 增速）

> 先定行业，再定指标，不套用通用模板。

## 二、统计块格式

Comps 表格底部必须附带统计汇总行：

```
┌────────────┬──────┬──────┬──────┬──────┐
│            │ Col1 │ Col2 │ Col3 │ ...  │
├────────────┼──────┼──────┼──────┼──────┤
│ Max        │      │      │      │      │
│ 75th %ile  │      │      │      │      │
│ Median     │      │      │      │      │
│ 25th %ile  │      │      │      │      │
│ Min        │      │      │      │      │
│ 目标公司    │      │      │      │      │
└────────────┴──────┴──────┴──────┴──────┘
```

**判断逻辑**：
- 目标在 **Median 附近** → 合理定价
- **低于 25th** → 可能低估（需确认无基本面原因）
- **高于 75th** → 可能高估（高增长可能合理）
- **永远看中位数，不看均值** — 均值被极端值扭曲

## 三、行业定制指标详解

### 消费：SSG / CAC / 复购率
- **同店增长 (SSG)**：开业 1 年以上门店收入增速，排除新开店干扰
- **CAC**：营销费用 / 新增客户数，上升是早期预警
- **复购率**：> 60% 通常意味着品牌护城河

### 科技：ARR / NDR / Rule of 40
- **ARR**：订阅收入年化值，比总收入更可靠
- **NDR**：老客户收入变化率，> 120% = 产品有粘性
- **Rule of 40**：收入增速% + 利润率% ≥ 40，平衡增长与盈利的黄金标准

### 金融：NIM / NPL / 拨备覆盖率
- **净息差 (NIM)**：银行最核心盈利指标
- **不良率 (NPL)**：关注趋势比绝对值更重要
- **拨备覆盖率**：> 150% 安全垫充足，< 130% 需警惕

### 工业：订单积压 / ROIC
- **Book-to-Bill**：> 1 = 需求旺盛，< 1 = 需求走弱
- **ROIC**：长期 > WACC 才创造价值

### 医药：研发管线 / 研发收入比
- **研发管线**：Phase III 管线价值远高于 Phase I
- **研发/收入比**：15-25% 为合理区间

## 四、可比公司筛选

### 三层筛选漏斗

1. **行业分类**：GICS 或申万二级，同细分行业，不是"都是消费品"
2. **商业模式**：收入结构、客户类型、成本结构是否可比
3. **规模区间**：收入 0.3x-3x，市值差异不超过 10 倍

### 数量要求
- 最少 3 家，推荐 5-8 家，最多 10 家
- 超过 10 家说明行业定义太宽

### 特殊情况
- **稀缺标的**：可扩大到相邻行业，但需注明
- **多元化公司**：按板块分拆估值 (SOTP)
- **次新股**：上市不足 2 年慎用 Comps

## 五、A 股 / 港股特殊调整

### AH 溢价
- A 股通常比 H 股贵 20-40%（历史均值约 30%）
- AH 公司需分别列示，注明溢价率

### 流动性折价
- 日均成交额 < 5000 万 → 给 10-20% 折价
- 在表中标注日均成交额，低流动性标星号

### 估值区间参考

| 板块 | PE 中位数参考 | 说明 |
|------|-------------|------|
| 沪深 300 | 12-18x | 大盘蓝筹，机构定价 |
| 中小盘成长 | 25-40x | 增速溢价，警惕泡沫 |
| 港股通 | 8-15x | 整体估值偏低 |
| 科创/创业板 | 30-60x | 流动性 + 政策溢价 |

> 不要跨板块比较 PE。创业板 60x 不一定贵，沪深 300 的 15x 不一定便宜。

### A 股特色补充指标
- **机构持仓比例**：北向资金 + 公募占比
- **限售股解禁**：未来 6 个月解禁比例
- **大股东质押率**：高质押是风险信号

## 六、数据来源优先级

```
1. API 实时数据（东财/天天/）  → 最准确，直接引用
2. 公司财报（年报/半年报）     → 最权威，注意时效性
3. 券商研报数据               → 可参考，可能有偏见
4. 财经网站搜索               → 交叉验证用，非唯一来源

绝对禁止：
✗ 用估算数据填充缺失值
✗ 用"行业平均"代替实际数据
✗ 混用不同会计准则（IFRS vs CAS）
✗ 数据过期超 1 年且不注明
```

**缺失数据处理**：单个指标缺失标"N/A"；整家公司数据不足则移除。宁可少一家，不用猜的数据。

## 七、常见错误

1. **行业定义太宽** — 把所有科技公司放一起比较
2. **忽视增长率差异** — 30% 增速和 5% 增速的公司直接比 PE
3. **用均值代替中位数** — 一个 PE 500x 的公司拉高整个均值
4. **跨周期比较** — 周期高点利润算出的 PE 看起来便宜但实际不便宜
5. **忽视资本结构** — 高杠杆和低杠杆公司的 PE 不可直接比
6. **将 Comps 当绝对真理** — 市场整体高估时，"合理估值"也偏高

## 九、适用与失效场景

### ✅ 适用
- 行业内有多家上市公司（> 5 家），商业模式相似
- 市场定价相对理性，无严重投机泡沫
- 需要快速得到"大致合理"的估值区间
- 作为 DCF 的交叉验证

### ❌ 失效
- **行业唯一标的**：没有可比对象
- **极端周期**：周期底部 PE 极高，顶部极低
- **重大事件**：并购、政策剧变，历史估值失效
- **市场整体极端**：牛市顶部或熊市底部
- **会计差异过大**：不同政策导致数据不可比

### 🔄 推荐组合
- Comps + DCF → 最经典，相对 + 绝对交叉验证
- Comps + SOTP → 多元化集团
- Comps + 交易法 → 并购场景

---

> **最后一句**：Comps 告诉你的是"市场怎么给这类公司定价"，不是"这家公司值多少钱"。两者之间，就是超额收益空间。
