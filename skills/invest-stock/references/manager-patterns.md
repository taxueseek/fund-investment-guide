# 基金经理共性框架——多经理交叉提炼

> 基于多位顶级基金经理公开方法论提炼的共性规律。用于增强个股和基金分析的深度。

---

## 一、共性框架：好经理都在问的五件事

无论风格如何，顶级基金经理的决策框架几乎都围绕五个核心问题：

| 问题 | 景气学派表述 | 价值学派表述 | 通用含义 |
|------|-------------|-------------|---------|
| 景气从哪来？ | "研究清楚通胀从何而来" | "收入利润增长的可持续性" | 涨价的底层逻辑是什么？可持续吗？ |
| 中国优势在哪？ | "全球视野+中国比较优势" | "全世界最便宜的资产" | 在全球产业链里，确定性最高的一环是什么？ |
| 利润弹性有多大？ | "ROE从低到高，当下越低空间越大" | "戴维斯双击" | 市场对这个标的的预期有多低？修复弹性有多大？ |
| 怎么退出？ | "底层逻辑变坏就卖" | "估值到了离谱的水平就卖" | 入场时就想好出场条件 |
| 客观还是主观？ | "对结果平淡，对过程在意" | "不预测，只应对" | 区分「愿望」和「事实」 |

## 二、景气度投资框架

### 两种通胀，两种爆发力

```
传统周期通胀 = 供需错配 → 爆发力有限，周期短
科技成长通胀 = 供给端创造需求 → 爆发力更强，周期长
```

**实操判断**：
- 问「这个涨价是需求突然爆发，还是新技术让原本不存在的需求出现了？」
- 后者更持久：AI 算力、新能源车、智能手机都是「创造了原本没有的需求」

### 产业链分析三步法

1. **全球视野找变化**：什么技术/需求正在发生不可逆的变化？
2. **顺产业链找通胀环节**：这个变化让哪一层供不应求、持续涨价？
3. **落到中国比较优势**：哪一层中国有全球优势？

**经典案例**：AI Capex ↑ → 算力网络需要传输 → 远距离靠光通信 → 中国光学传输全球占优 → 光通信

## 三、选股四象限（多经理交叉）

| | 高 ROE | 低 ROE |
|---|---|---|
| **高景气** | 最佳：高景气+高ROE，但估值通常贵 | 次优：高景气+低ROE，弹性最大 |
| **低景气** | 陷阱：高ROE可能是杠杆或不可持续 | 回避：低景气+低ROE，价值毁灭 |

**关键洞察**：真正有超额收益空间的标的多在「高景气 × 低 ROE」象限——赚的是「市场从低估到修复」的钱，而不是「一直好一直贵」的钱。

## 四、卖出纪律（多经理共识）

| 卖出触发条件 | 共识 |
|-------------|------|
| 底层逻辑变坏 | 第一条件——行业逻辑破了，不走 |
| 估值极端 | 核心条件——价格远超合理价值 |
| 交易拥挤 | 短期博弈激烈时适当减仓 |
| 发现更好标的 | 机会成本考量 |

## 五、组合管理共性

| 维度 | 共识 |
|------|------|
| 集中度 | 适中集中（40-60%），不过度分散也不过度集中 |
| 换手率 | 因人而异，但都「动态调整」而非买入躺平 |
| 仓位管理 | 淡化择时，调行业比例而非调仓位 |
| 回撤观 | 不追求低回撤，追求高弹性——靠选对景气方向降回撤 |

## 六、对分析的启发

### 个股分析时多问一句

在 invest-stock 的三关审查中，加入「景气度」维度：

1. **景气方向**：这个公司站在哪个产业周期的什么位置？
2. **通胀属性**：它的涨价能力来自供需错配还是供给端创造需求？
3. **全球优势**：在全球产业链里，中国有确定性优势吗？
4. **ROE 弹性**：当前 ROE 在什么位置？是「低位待修复」还是「已经高位」？
5. **周期阶段**：这个产业处于导入期、成长期还是成熟期？

### 基金分析时多问一句

在 invest-fund 的三关审查中，加入「经理方法论」维度：

1. **经理的底层框架是什么**？景气度投资？价值投资？逆向投资？
2. **他的中国优势判断**？在全球产业链里看好哪一环？
3. **他的选股偏好**？大盘/小盘？高ROE/低ROE？集中/分散？
4. **言行一致**？季报持仓和公开表态对得上吗？
