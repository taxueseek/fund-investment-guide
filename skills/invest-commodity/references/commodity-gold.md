# 黄金十维度增强（吸收自 gold-analyzer）

> 在 invest-commodity 三关审查基础上，对黄金做**十维度量化评分**并给出信号强度。
> 数据来源：invest-cli（ttfund gold / Wind）、公开检索。

## 数据字段

| 模块 | 关键字段 |
|------|---------|
| 行情 | 上金所基准价（au9999/au_td）、上期所黄金主力、央行黄金储备 |
| 宏观 | CPI 同比、美债收益率、CFTC 持仓、道指/标普/纳指 |
| 风险 | VIX、USDCNY、美元指数 DXY |
| 资讯 | 新闻标题/摘要/时间/来源 |

注意时效字段：`date / freshness_days / is_stale / is_backfilled`，过期或回填数据必须在输出中标明。

## 十维度评分

| 维度 | 权重 | 主要字段 | 高分说明（利多黄金） |
|------|------|---------|------|
| 地缘风险 | 10% | 资讯 | 地缘冲突升级 |
| 股市波动 | 10% | VIX + 全球股指 | VIX 高、股市跌 |
| 期货持仓 | 10% | CFTC + 黄金期货 | 多头增 |
| 技术面 | 10% | au9999/au_td 等 | 突破/多头排列 |
| 实际利率 | 15% | 美债收益率 + CPI | 实际利率低/负 |
| 通胀 | 15% | CPI 同比/环比 | 通胀上行 |
| 就业 | 10% | 失业率/非农 | 就业弱 |
| 人民币汇率 | 8% | USDCNY | 人民币贬值压力 |
| 美元信用 | 6% | DXY + 美债 | 弱美元 |
| 央行购金 | 6% | 央行黄金储备 | 央行持续增持 |

**信号映射**：≥7 强烈买入；5–7 买入/增持；4–5 持有观望；3–4 减持/谨慎；≤3 卖出/规避。
